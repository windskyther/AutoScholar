# 修复后真实正常基线 v9

本方案只复验一次正常基线，用于确认 Snapshot 输出修复后真实模型能完成现有任务。
准备过程免费；真实执行须单独确认下面的调用范围，且必须使用准备时冻结的源码。

## 范围与停止条件

- 单组 `normal-baseline`，最多 **12 次 LLM、0 次 Tavily**，不追加故障或消融任务。
- 每次最大输出 8192 token；任务总 token 阈值 120000，最后一次响应可能越过阈值。
- 请求最多 32768 UTF-8 字节，沿用局部编辑参数限制与截断响应整体拒绝规则。
- 既有有界协议纠正也计入 12 次上限；没有 HTTP 自动重试或整轮重跑。
- 任务使用公开 MNIST 子集、预置训练模板、自编公开检索语料。真实模型负责规划、
  证据整理、源码就绪判断及审查；训练和独立检查点核验在本地隔离 Docker 执行。
- 发送公开目标、工具定义、模板源码、公开证据及检查结果，不发送本地设计文档、
  `.env` 文件或密钥内容；API 密钥仅用于供应商认证。
- 源码、夹具、历史摘要或冻结资源不一致时拒绝派发；模型身份漂移、截断、
  供应商错误、预算耗尽、核验失败或资源清理失败均不判为通过。

正常验收要求 research/code/train 各执行一次，强制代码检查和独立产物核验通过，
实际请求与任务用量一致，只有一个观察到的模型身份，历史和源码保持不变，资源清理成功。
声明代码就绪不能代替检查。模型如果没有编辑，结果也不能宣称验证过真实局部编辑。

固定沙箱镜像：`5f8f4de620311dfe4303b679048b9eced521ddf3201c5d743ae212b16e2c0e3a`。
固定 MNIST 摘要：`f4d6a18adf158439195f76a1267a7918723faf6ae121eff9914ed83afc53c476`。

## 可复核入口

免费准备（干净且已提交的 dev 源码）：

```powershell
.venv\Scripts\python.exe -m autoscholar.evaluation paired --protocol-version 9 --history-index data/evaluation/paired-history-bb233e501cd642ce989a4c31651d181d/index.json
```

输出新 `paired-plan-<UUID>/plan.json`，绑定提交号、夹具摘要和保护 760 个文件的历史索引。
准备不读取 `.env`，不创建付费声明，不调用供应商。旧 v8 消耗声明必须在保护范围内。

获得新的明确授权并检查独立控制器后，执行入口为：

```powershell
.venv\Scripts\python.exe -m autoscholar.evaluation paired --protocol-version 9 --allow-paid --plan <本次冻结的plan.json> --approval-id <新授权编号> --sandbox-container <独立控制器>
```

此模板不是授权。独占声明 `live-baseline-v9-claim.json` 防止换编号重跑；每次物理请求
由新的授权账本记录，不复用 v8 剩余 173 次空间。发生失败时保留未知结果、已消费用量和原始证据。
