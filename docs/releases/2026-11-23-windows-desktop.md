## 功能范围

桌面版复用 React 工作台、Python 研究工作流和报告导出，提供资料调研、论文综述、技术对比、研究方案、项目文档分析五种模式，以及项目证据库、模型配置、用量统计和任务管理。Tauri 使用系统 WebView2，安装包自带 Python 和 Windows 版 Qdrant。项目数据、任务和缓存保存在本机 SQLite 中，密钥使用当前 Windows 用户的 DPAPI 保护。PDF 检索按需启动模型与 Qdrant 进程，空闲后自动释放。
