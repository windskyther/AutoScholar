## 单次授权范围

| 项目 | 上限或范围 |
|---|---|
| 任务 | 一个 `normal-baseline`，没有额外故障注入或消融组 |
| LLM | 最多新增 12 次物理请求，协议纠正也占用此额度 |
| Tavily / Semantic Scholar | 不调用；检索使用自编公开封闭语料 |
| Token | 任务阈值 120000，最后一次响应可能越过阈值 |

| 请求 | 最多 32768 UTF-8 字节，Snapshot 继续保留反馈空间 |
| 重试 | 无 HTTP 自动重试、整轮重跑或旧额度复用 |
| 训练 | 固定公开 MNIST 子集和预置 MLP/CNN 模板，隔离本地 CPU 执行 |

发送内容是公开研究目标、工具 schema、模板代码、公开证据和检查结果。
API 密钥仅用于供应商认证；不发送本地设计文档、`.env` 文件或密钥内容。

任务内引擎沿用 12 次模型调用、600 秒、最多一次重规划、两次训练的预算天花板；
正常基线的验收必须是 research/code/train 各执行一次，不将恢复路径或重复训练算作本组成功。

## 冻结和停止条件

新计划冻结干净 dev 提交、公开夹具、资源摘要、785 个历史文件的索引，
以及模型名、配置的兼容模式、实际启用的兼容模式与终端摘要。
准备时读取本地必要的 LLM 配置；清单仅保存公共配置和终端 SHA-256，不保存密钥或终端明文。
此步骤不联网、不创建付费声明，保持旧 v8/v9 的免费准备行为。

v10 要求实际启用 `deepseek` 兼容模式；官方地址可由 `auto` 精确识别，兼容网关需显式配置。
执行前及每次模型调用前重新校验计划、源码、历史与公共配置。即使配置和计划同时被改写，
也必须与执行开始时保留的清单一致，否则拒绝继续派发。

供应商错误、截断、未知或不匹配用量、观察到的模型身份变化、独立核验失败、资源异常、
预算耗尽或冻结内容改变均不判为通过。保存部分证据及未知状态，不自动补跑一整轮。
非 200 响应保留有限词表的诊断记录，不保存任意供应商原文或认证信息。

`live-baseline-v10-claim.json` 是独占执行声明，配合新的授权账本阻止换编号重跑。
旧 v8 剩余 173 次空间和 v9 剩余六次空间均封存，原失败结论和未知用量不改分。

正常验收要求强制代码检查、一次真实训练、独立检查点/产物核验、持久化记录和实际请求用量
相互一致。若模型直接声明代码就绪而未编辑，本组不能宣称验证过真实局部编辑。
