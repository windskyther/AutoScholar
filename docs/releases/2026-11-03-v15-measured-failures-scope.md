# v15：完成固定版本的 15 组真实配对测量

按用户“继续完成剩余任务”的指示，在已验证的显式依赖数组修复上执行一轮新的测量，不增加付费预热。
三个场景（normal、recover、deception）各运行 baseline、no_planner、no_reviewer、no_memory、no_replanning。
固定源码、公开输入、模板、封闭语料、CPU/MNIST 子集、模型、终端、兼容配置与资源；旧观察不拼接为本轮结果。

- 本轮最多新增 **180 次物理 LLM、0 次 Tavily / Semantic Scholar**；每组最多 12 次，纠错计入其中。
- 每组 token 阈值 120000，最后一次响应可能越过阈值；每次输出上限 8192，请求上限 32768 UTF-8 字节。
- 每组引擎限时 600 秒、外层限时 660 秒，最多两次训练、一次重规划、零次代码修复；协调器与 Coding 共用一次协议纠错。
- 不自动 HTTP 重试或整组重跑，不复用旧授权剩余额度。只发送公开任务、schema、模板和测试证据；密钥只用于认证。
- 冻结清单继续逐项保护 v14 在内的 1591 个历史文件；旧版本的未测、未知、失败和验收标志保持原值。

本轮预先明确区分任务失败与测量中断：完整 HTTP 200、用量与物理回执一致的终止性工具协议错误，
记为 `task_success=false`，保留错误、原始响应和计费记录；该任务立即停止，不再调用模型。
非基线消融项发生这种失败时继续其余项目。这不代表任务成功，也不补写计划或生成自动 PASS。
截断、网络错误、未知或不一致用量、源码/模型/资源绑定改变、资源未清理，仍停止整轮。
三个基线及关闭重规划负对照的既有门槛不变；基线失败停止，负对照未达门槛则不得验收。
这个分类只在 v15 启用；v8–v14 协议与历史结果不回溯修改。

根 DAG 仍须 research → coding → experiment，显式填写 `[]`、`[research_id]`、`[coding_id]`。
错误计划在子任务执行前拒绝，最多使用原有一次计量纠错，不自动替换。
验收要求四个对比均有三个同版本配对，以及控制、物理用量、原始证据、清理和最终组合回归通过。
不要求消融项全部成功、移除组件必然变差或统计显著。三组异质配对只支持有限工程观察。

最终结论在 [验收报告](../../evaluation_report.md) 单独记录；本文件只是冻结执行范围。
公开封闭语料、预置代码、MNIST 128/128 子集和一次 epoch 不代表开放网络研究、从零编程或生产可用性。
`.env`、本地设计文档及 `data/` 运行资料不提交。
