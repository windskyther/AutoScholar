## 直接原因与安全停止

第 7 次响应的 `finish_reason=length`，输出用量达到既定 **8192-token 上限**，其中供应商报告
reasoning tokens 为 6146。响应带有两条 `edit_file`：第一条参数可解析，第二条 JSON 被截断。
请求已设置 `parallel_tool_calls=false`，模型仍返回多条调用；此处不能靠设置视为符合协议。

LLM Provider 解析器在交给执行器前拒绝整个不完整响应。只读审计确认 Coding 的持久化工具记录
为零，磁盘源码与该次请求里的完整源码快照逐字一致。没有执行第一条编辑，没有伪造就绪或
自动审查通过，也没有通过提高输出、调用或请求上限绕过失败。
现有规则不对 `finish_reason=length` 自动重试，因此实际 7 次调用后立即停止后续排程。
