## 固定任务与预算

三个场景分别运行五种配置，共 15 个新任务，按表中场景顺序和列顺序串行执行：

| 场景 | baseline | no_planner | no_reviewer | no_memory | no_replanning |
|---|---|---|---|---|---|
| normal | 正常基线 | 关闭 Planner | 关闭 Reviewer | 关闭 Memory | 关闭重规划 |
| recover | 故障恢复基线 | 同输入干预 | 同输入干预 | 同输入干预 | 故障后的停止负对照 |
| deception | 伪造指标基线 | 同输入干预 | 同输入干预 | 同输入干预 | 同输入干预 |

- **最多新增 180 次 LLM、0 次 Tavily/ Semantic Scholar**，每个任务最多 12 次。
- 每个任务 token 阈值 120000；15 个阈值之和是 1800000，但不是硬总量上限，
  每组最后一次响应可能跨过阈值。单次输出上限 8192 token。
- 实际请求最多 32768 UTF-8 字节，继续保留 Snapshot 反馈空间和本地参数限制。
- 每任务沿用 600 秒、最多一次重规划和两次训练的引擎预算，不跨任务挪用剩余额度。
- 每任务只尝试一轮，无 HTTP 自动重试或整组自动重跑；已有有界协议纠正计入 12 次上限。
- 费用随实际供应商调用产生；没有可审计单价时金额保持未知。

研究使用自编公开封闭语料，代码使用预置的可运行模板，实验为固定 128/128 样本、
一次 epoch 的 MNIST MLP/CNN 工程子集。不是开放网络研究或从零代码生成能力的认证。
只发送公开目标、schema、模板源码、公开证据和测试结果；密钥只用于供应商认证，
不发送 `.env` 文件、本地设计文档、密钥内容或现有应用数据库。

## 固定条件与停止规则

新清单绑定干净 dev 提交、公开夹具、资源摘要、833 个历史文件索引，以及模型配置、
实际兼容模式和终端摘要。准备时读取必要的本地 LLM 配置，但只保存公共字段与终端 SHA-256。
每次派发前检查源码、清单和公共配置；不能同时改写清单与配置来绕过执行开始时的冻结记录。
思考模式和 schema 兼容策略沿用已验证的 DeepSeek 修复。

场景基线未通过、供应商错误、未知或不匹配用量、干预配置不正确、资源清理失败，
或源码/历史/配置/模型返回标识变化时停止后续派发。已开始任务和未执行任务分别保留原状，
未知结果不填零，不靠补跑改分。
`live-paired-v11-claim.json` 和独立授权账本阻止换编号重跑。
v8/v9/v10 的剩余额度均不复用。

完整配对验收要求 15 个观测在同一冻结协议下测量完成，每个记录的执行检查均通过。
正常基线须完成一次训练；恢复基线须保留上游代码和计划，只重跑实验、训练两次；
伪造指标基线须实际训练并被独立 oracle 拒绝。关闭重规划的恢复负对照须触发一次故障、
停止于 `evaluation_replanning_disabled`，没有第二次训练。
负对照及完整统计覆盖在最终汇总时核对，不把变体任务失败自动当成测量失败或成功。

四个组件分别与基线按三个场景配对，报告真实二元任务成功差异、精确配对二项符号检验和
四个对比的 Holm 校正。每个对比只有三个异质工程样本，不能推导普遍的组件收益。
不要求某个组件的消融一定变差，也不把统计显著性作为通过条件。
只绑定配置与返回的模型标识，不能保证供应商内部权重和随机采样完全可复现。

评测代码在 dev；main 同步此公开准备报告，未将 191 项称为 main 完整回归。
免费准备会生成新的 `paired-plan-<UUID>/plan.json`，不创建执行声明、不调用供应商：

```powershell
.venv\Scripts\python.exe -m autoscholar.evaluation paired --protocol-version 11 --history-index data/evaluation/paired-history-d9a56a3c7b0d49d889a7c81950def5d0/index.json
```

用户确认本轮清单和预算后，才可通过新授权编号执行：

```powershell
.venv\Scripts\python.exe -m autoscholar.evaluation paired --protocol-version 11 --allow-paid --plan <本轮冻结的plan.json> --approval-id <新授权编号> --sandbox-container <独占控制器>
```
